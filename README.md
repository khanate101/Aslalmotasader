# أصل المتصدر | Asl Almotasader

منصة عربية لإدارة وعرض الرحلات البرية والخدمات السياحية في اليمن والمملكة العربية السعودية.

## التقنية
- PHP 8.2+ (بدون إطار عمل ثقيل لتسهيل الاستضافة التقليدية).
- MariaDB 10.6+ / MySQL 8.
- PDO مع الاستعلامات المحضّرة.
- واجهة عربية RTL متجاوبة.

## الحالة
هذا المستودع يبدأ الآن ببنية MVP قابلة للتوسع. لا تُعتبر المنصة جاهزة للإنتاج قبل ضبط أسرار البيئة، تثبيت قاعدة البيانات، إنشاء أول مدير، تفعيل HTTPS، واختبار سير الحجز والصلاحيات على الاستضافة الفعلية.

## التشغيل
1. انسخ `.env.example` إلى `.env` واضبط بيانات قاعدة البيانات.
2. أنشئ قاعدة بيانات UTF8MB4 ثم نفّذ `database/schema.sql`.
3. وجّه Document Root إلى مجلد `public/`.
4. أنشئ أول مدير بأمر CLI: `php scripts/create_admin.php`.
5. افتح الموقع من المتصفح.

## إعداد واتساب
تُحفظ الطلبات أولاً في قاعدة البيانات، ثم يُفتح رابط WhatsApp برسالة مُعبأة. فتح الرابط لا يعني إرسال الرسالة تلقائياً ولا يؤكد الحجز.

## الأمان
- كلمات المرور تُخزن عبر `password_hash()`.
- الجلسات وCSRF والتحقق من الصلاحيات على الخادم.
- لا تضع ملف `.env` أو كلمات مرور حقيقية في Git.
- يجب تشغيل الموقع عبر HTTPS في الإنتاج.
