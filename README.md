# أصل المتصدر | Asl Almotasader

منصة عربية لإدارة وعرض الرحلات البرية والنقل وخدمات العمرة والتأشيرات والزيارات بين اليمن والمملكة العربية السعودية، مع لوحة إدارة مركزية وشركات وفروع وموظفين.

## التقنية ومتطلبات التشغيل
- PHP 8.2 أو أحدث.
- MariaDB 10.6+ أو MySQL 8.
- امتداد PDO MySQL وامتداد mbstring.
- خادم Apache مع mod_rewrite (أو إعداد Nginx مكافئ).
- HTTPS إلزامي قبل استقبال بيانات العملاء.

## ما يتضمنه المستودع حالياً
- واجهة عامة عربية RTL، بحث الرحلات وصفحات تفاصيل الرحلة والحجز.
- إدارة الرحلات وشركات النقل وتحديد النشر والحالة وتعديل البيانات.
- إدارة برامج العمرة وخدمات التأشيرات والزيارات.
- استقبال طلبات العمرة والخدمات ومتابعة حالاتها.
- إدارة الموظفين وحساباتهم وأدوارهم وصلاحيات الأدوار.
- إدارة الفروع وسجل نشاط الإدارة.
- قاعدة العملاء، إحصائيات وتقارير الحجوزات وتصدير CSV.
- إعدادات اسم المنصة ورقم واتساب والعملة الافتراضية.
- حماية CSRF، تخزين كلمات المرور باستخدام password_hash، استعلامات PDO محضّرة، وتقييد مؤقت لمحاولات تسجيل الدخول الفاشلة.
- GitHub Actions لفحص الصياغة النحوية لملفات PHP عند كل دفع إلى main.

## التثبيت على استضافة PHP
1. أنشئ قاعدة بيانات MariaDB بترميز utf8mb4 ومستخدم قاعدة بيانات محدود الصلاحيات.
2. انسخ `.env.example` إلى `.env` في جذر المشروع، ثم أدخل بيانات قاعدة البيانات الصحيحة.
3. استورد `database/schema.sql` من phpMyAdmin أو أداة إدارة قواعد البيانات. يمكن إعادة تشغيل ملف المخطط بعد تحديثه لتطبيق الإضافات والصلاحيات الجديدة؛ يستخدم CREATE TABLE IF NOT EXISTS وINSERT IGNORE ولا يحذف الجداول أو بياناتها.
4. اجعل مجلد `public/` هو Document Root للموقع. لا تجعل جذر المستودع متاحاً للعامة.
5. تأكد من تفعيل PDO MySQL وmbstring وmod_rewrite.
6. أنشئ حساب مدير النظام من سطر أوامر الخادم:
   ```bash
   php scripts/create_admin.php USERNAME 'LONG-UNIQUE-PASSWORD' 'اسم المدير'
   ```
   كلمة المرور يجب ألا تقل عن 12 حرفاً. لا تستخدم كلمة مرور المثال أو تشارك كلمة المرور في المحادثات.
7. افتح `/admin/login.php` وسجل الدخول، ثم أضف المدن/الشركات والرحلات وبرامج العمرة والخدمات والموظفين.
8. اختبر الحجز والتأكيد والإلغاء والصلاحيات على بيئة تجريبية قبل نشر بيانات حقيقية.

## إعداد البيئة
المتغيرات الأساسية: `APP_NAME`, `APP_ENV`, `APP_DEBUG`, `APP_URL`, `APP_TIMEZONE`, `WHATSAPP_NUMBER`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`.
اجعل `APP_DEBUG=false` في الإنتاج. لا ترفع ملف `.env` إلى Git.

## ملاحظات مهمة قبل الإنتاج
هذا المستودع يحتوي على وحدات تشغيل وإدارة أساسية، لكنه لا يصبح جاهزاً للإنتاج بمجرد رفع الملفات. يلزم تنفيذ اختبار قبول كامل على خادم PHP/MariaDB فعلي، ومراجعة صلاحيات كل دور وشركة، وضبط النسخ الاحتياطي ومراقبة الأخطاء وسياسة الاحتفاظ بالبيانات، واختبار تدفق واتساب يدوياً. فتح رابط واتساب لا يرسل الرسالة تلقائياً ولا يعني تأكيد الحجز.


## إنشاء المدير الأول من المتصفح (إعداد لمرة واحدة)
يمكن استخدام `public/setup-admin.php` لإنشاء أول حساب مدير دون تسجيل دخول سابق:
1. أنشئ مفتاحاً عشوائياً طويلاً (مثلاً `openssl rand -hex 32`) وضعه في `INITIAL_ADMIN_SETUP_KEY` داخل ملف `.env`.
2. افتح `/setup-admin.php` وأدخل مفتاح الإعداد واسم المدير واسم المستخدم وكلمة المرور.
3. الصفحة ترفض العمل إذا كان هناك مدير نظام رئيسي مسجل، وتستخدم قفلاً على قاعدة البيانات لمنع إنشاء مديرين بالتزامن.
4. بعد نجاح الإنشاء احذف `public/setup-admin.php` من نسخة الخادم ومن المستودع. لا تنشر الموقع للعامة قبل إتمام هذه الخطوة.

## اختبار محلي على Android
راجع الدليل `docs/TERMUX-LOCAL-TEST.md` لتشغيل PHP وMariaDB في Termux وفتح المعاينة من الهاتف والكمبيوتر على شبكة Wi-Fi نفسها.
