# تجربة أصل المتصدر محلياً على هاتف Android باستخدام Termux

هذا الدليل يشغّل نسخة اختبار على الهاتف نفسه. لا يحتاج إلى استضافة أو رفع الموقع للإنترنت. ويمكن فتحه من كمبيوتر متصل بنفس شبكة Wi-Fi لمعاينة التصميم على شاشة أكبر.

> خادم PHP المدمج مخصص للتطوير والاختبار فقط. لا تستخدمه لاستضافة عامة أو لاستقبال بيانات عملاء حقيقية.

## 1) تثبيت الأدوات

افتح Termux ونفّذ:

```bash
pkg update && pkg upgrade -y
pkg install git php mariadb nano openssl -y
```

تحقق من PHP وامتداداته:

```bash
php -v
php -m | grep -Ei 'pdo_mysql|mbstring'
```

يجب أن يظهر `pdo_mysql` و`mbstring`. إذا لم يظهر أحدهما، لا تكمل حتى نعرف إصدار PHP وحزم Termux لديك.

## 2) تنزيل المشروع

```bash
cd ~
git clone https://github.com/khanate101/Aslalmotasader.git
cd Aslalmotasader
```

إذا كان المجلد موجوداً مسبقاً:

```bash
cd ~/Aslalmotasader
git pull origin main
```

## 3) تشغيل MariaDB محلياً

ابدأ الخادم:

```bash
mariadbd-safe &
```

انتظر عدة ثوانٍ ثم جرّب الاتصال:

```bash
mariadb -u root
```

إذا كان root محمياً بكلمة مرور، استخدم `mariadb -u root -p`.

داخل شاشة MariaDB أنشئ قاعدة ومستخدماً للتطبيق. استبدل كلمة المرور في المثال بكلمة قوية خاصة بك:

```sql
CREATE DATABASE aslalmotasader CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'aslapp'@'127.0.0.1' IDENTIFIED BY 'PUT_A_LONG_RANDOM_PASSWORD_HERE';
GRANT ALL PRIVILEGES ON aslalmotasader.* TO 'aslapp'@'127.0.0.1';
FLUSH PRIVILEGES;
EXIT;
```

لا تستخدم كلمة المرور المكتوبة في المثال كما هي.

## 4) إعداد ملف البيئة واستيراد الجداول

```bash
cp .env.example .env
nano .env
```

عدّل القيم التالية في `.env`:

```ini
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8080
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=aslalmotasader
DB_USERNAME=aslapp
DB_PASSWORD=ضع_كلمة_مرور_مستخدم_قاعدة_البيانات
SESSION_SECURE=false
INITIAL_ADMIN_SETUP_KEY=ضع_هنا_مفتاحاً_عشوائياً_طويلاً
```

ولإنشاء مفتاح عشوائي آمن، نفّذ في نافذة Termux أخرى أو قبل تحرير الملف:

```bash
openssl rand -hex 32
```

انسخ الناتج إلى `INITIAL_ADMIN_SETUP_KEY` في `.env`. احتفظ به خاصاً ولا تضعه في GitHub.

احفظ الملف في nano عبر Ctrl+O ثم Enter ثم Ctrl+X.

استورد الجداول:

```bash
mariadb -h 127.0.0.1 -u aslapp -p aslalmotasader < database/schema.sql
```

أدخل كلمة مرور مستخدم قاعدة البيانات عند الطلب.

## 5) فحص ملفات PHP

```bash
find . -name '*.php' -not -path './.git/*' -print0 | xargs -0 -n1 php -l
```

ينبغي أن ترى `No syntax errors detected` لكل ملف. إذا ظهر خطأ، انسخ رسالة الخطأ كاملة.

## 6) تشغيل الموقع

من داخل مجلد المشروع:

```bash
php -S 0.0.0.0:8080 -t public
```

اترك جلسة Termux مفتوحة. على الهاتف افتح Chrome أو أي متصفح على:

`http://127.0.0.1:8080`

## 7) إنشاء المدير الأول لمرة واحدة

افتح على الهاتف:

`http://127.0.0.1:8080/setup-admin.php`

أدخل:
- مفتاح التهيئة الذي وضعته في `.env`.
- اسم المدير.
- اسم المستخدم.
- كلمة مرور لا تقل عن 12 حرفاً، ثم تأكيدها.

صفحة الإعداد لا تتطلب تسجيل دخول إداري، لكنها تتطلب المفتاح السري. كما أنها ترفض إنشاء حساب إذا كان هناك أي مستخدم سابق، وتغلق نفسها بعد الإنشاء.

بعد ظهور نجاح الإنشاء، احذف الملف من المشروع:

```bash
rm public/setup-admin.php
```

ثم افتح:

`http://127.0.0.1:8080/admin/login.php`

وسجّل الدخول بالبيانات التي أنشأتها.

## 8) مشاهدة التصميم من الكمبيوتر

1. اجعل الهاتف والكمبيوتر على شبكة Wi-Fi نفسها.
2. افتح جلسة Termux ثانية ونفّذ:

```bash
ip route get 1.1.1.1
```

ابحث عن قيمة `src` في الناتج؛ هذا هو عنوان IP المحلي للهاتف غالباً، مثل `192.168.1.25`.
3. على الكمبيوتر افتح `http://192.168.1.25:8080` مع استبدال العنوان بعنوان هاتفك الفعلي.
4. افتح الصفحة الرئيسية ولوحة الإدارة وجرّب تغيير عرض المتصفح لمحاكاة الهاتف.

إذا لم يتصل الكمبيوتر، تأكد من أن الجهازين على الشبكة نفسها وأن الشبكة لا تمنع اتصال الأجهزة ببعضها. لا تفتح المنفذ على الإنترنت.

## 9) إدخال بيانات تجريبية

بعد تسجيل الدخول:
- افتح الشركات وأضف/عدّل بيانات شركات النقل.
- افتح الرحلات وأضف رحلة تجريبية بتاريخ مستقبلي وسعر وعدد مقاعد.
- افتح برامج العمرة وأضف برنامجاً تجريبياً.
- افتح الخدمات وأضف خدمة تأشيرة أو زيارة.
- افتح الموقع العام وتحقق من ظهور البيانات.
- جرّب إرسال طلب حجز ببيانات اختبار، ثم راجعه من لوحة الإدارة.

استخدم أسماء وأرقاماً تجريبية فقط. لا ترفع صور جوازات أو هويات أو مستندات حقيقية إلى نسخة الاختبار.

## إيقاف الخوادم

أوقف خادم PHP بالضغط على `Ctrl+C` في جلسته. لإيقاف MariaDB:

```bash
pkill mariadbd
```

إذا واجهت خطأ، أرسل نص الخطأ كما ظهر ونتيجة `php -m` و`mariadb --version`، ولا تحذف مجلد قاعدة البيانات.
